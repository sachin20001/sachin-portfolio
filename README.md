# Sachin — Portfolio

A lightweight, responsive single-page portfolio built with HTML, CSS, and vanilla JavaScript. It has no build step, backend, tracking, or runtime dependencies. The typefaces load from Google Fonts when network access is available; system fallbacks are included.

## Preview locally

Open `index.html` directly in a browser, or serve the folder with any static file server. For example, if Python is installed:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait for deployment.
6. Open the published site and verify its links and assets.

All local assets use relative paths so the page works at a repository project path.

## Before publishing

Replace the clearly marked content placeholders and candidate project/skill content with confirmed information. Add the real résumé PDF at `assets/Sachin-Resume.pdf` and update the résumé CTA in `index.html` when it is available. Update the page title and description if the professional title changes.

Content to confirm before launch:

- Full professional display name and exact title.
- Résumé PDF.
- GitHub and LinkedIn URLs, plus a public professional email address.
- Verified employers, roles, dates, and approved experience descriptions.
- Which candidate projects are ready to publish, their accurate descriptions, technologies, and source/demo links.
- Candidate skills that reflect current experience.
- Optional approved profile photo or other personal assets.
